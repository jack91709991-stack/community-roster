# 自治会員名簿管理システム

自治会・町内会における会員名簿の管理・閲覧・編集をスマートフォンやパソコンから快適に行えるWebアプリケーションです。
Googleスプレッドシートをデータベースとしてリアルタイム連携し、Googleフォームからの新規入会申請を1クリックで安全に取り込める運用ワークフローを備えています。

## 🌟 主な特徴

- **スマホ・PC両対応（PWA対応）**:
  - 役員・班長が現場や集会所でスマホから軽快に利用可能。
  - ホーム画面に追加してアプリとして起動可能。
  - PCの大画面では一覧性の高いテーブル表示に自動対応。
- **Googleスプレッドシート連携（Google Apps Script）**:
  - スプレッドシートをデータベースとして活用（`Code.js` をコピペしてデプロイするだけ）。
  - オフラインキャッシュ（LocalStorage）を完備し、電波の悪い場所でも動作が止まりません。
- **Googleフォーム入会申請連携**:
  - Googleフォームから寄せられた入会申込を「入会申請受付」画面で確認。
  - 役員が所属班や役職を割り当てて「承認」ボタンを押すだけで、正式名簿マスターへ安全に反映。
- **会費集金チェックモード**:
  - 班長が集金に回る際、スマホでポンポンとタップするだけで「納入済/未納」を切り替え可能。
  - 班ごとの集金進捗率（％）をリアルタイム表示。
- **安心の防災・見守り管理**:
  - 高齢者の見守り対象フラグや、災害時の避難要支援フラグを可視化。
- **帳票印刷・CSV連携**:
  - A4印刷に最適化された印刷レイアウト（`@media print`）。
  - Excel互換のUTF-8 BOM付きCSVエクスポート＆インポート。

## 📊 Googleスプレッドシート・GAS連携手順

クラウドのスプレッドシートとデータを完全同期させる手順です：

1. **Googleスプレッドシートの作成**:
   - 新規Googleスプレッドシートを作成します。
2. **Apps Scriptの起動**:
   - スプレッドシートのメニュー「拡張機能」>「Apps Script」をクリックします。
3. **コードの貼り付け**:
   - プロジェクト内の `Code.js` の内容をすべてコピーし、エディタに貼り付けて保存（フロッピーアイコン）します。
4. **ウェブアプリとしてデプロイ**:
   - 右上の青い「デプロイ」>「新しいデプロイ」をクリック。
   - 歯車アイコンから「ウェブアプリ」を選択。
   - 設定:
     - **説明**: `自治会名簿API`
     - **次のユーザーとして実行**: `自分`
     - **アクセスできるユーザー**: `全員` (重要: ログイン認証なしでWebアプリから通信するため)
   - 「デプロイ」ボタンを押し、アクセス権限を承認。
5. **URLをアプリに登録**:
   - 発行された「ウェブアプリのURL」（`https://script.google.com/macros/s/.../exec`）をコピー。
   - 本アプリの「⚙️ 設定・印刷」タブを開き、「Google Apps Script Web App URL」に貼り付けて「保存して接続テスト」をクリック。
   - 画面右上のインジケーターが「🟢 接続中」になれば同期完了です！

## 📋 Googleフォーム入会申込連携の運用フロー

1. Googleフォームで「入会申込フォーム」を作成します。
   - 項目例: 氏名、フリガナ、電話番号、メールアドレス、住所、希望の班または近隣情報、世帯人数、ご家族構成など。
2. フォームの「回答」タブ >「スプレッドシートにリンク」で、上記のスプレッドシートを指定します。
3. 住民から送信された申込がスプレッドシートに蓄積され、本アプリの「📥 入会申請受付」タブに通知バッジ付きで自動表示されます。
4. 役員が申請内容を確認し、所属班を選んで「承認して名簿本登録」をクリックするだけで、正式名簿に追加されます。

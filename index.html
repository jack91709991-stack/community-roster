🏠 自治会基本設定
🏘️ ブロック・班の編成設定

自治会内のブロック（1ブロック〜5ブロック等）と所属する班を自由に設定・変更できます。スプレッドシート連携時は自動的に「システム設定」シートに保存され、どの端末からアクセスしても同じ編成が共有されます。

🎖️ 役員のマスタ設定

自治会内の役員（会長、副会長、会計、書記、各種専門委員、顧問など）の選択肢を自由に追加・削除・編集できます（※「班長」は専用項目で管理されます）。スプレッドシート連携時は自動的に「システム設定」シートに保存され、どの端末からアクセスしても同じ役員一覧が共有されます。

📊 Googleスプレッドシート連携 (GAS)
スプレッドシートのApps ScriptでデプロイしたWebアプリURLを入力すると、クラウドと双方向同期されます。
📝 スプレッドシート・GASの簡単セットアップ手順:
  1. Googleスプレッドシートを作成し、「拡張機能」>「Apps Script」を開きます。
  2. 本プロジェクト同梱の Code.js を丸ごとコピーして貼り付けます。
  3. 右上の「デプロイ」>「新しいデプロイ」で「ウェブアプリ」を選択。
  4. アクセスできるユーザーを「全員」にしてデプロイ。
  5. 発行されたURLを上記に入力して「保存して接続テスト」をクリックするだけで完了です！
🔐 役員合言葉（パスコード）・アクセス権限管理

役員の年度交代時には、スプレッドシート側の合言葉を変更するだけで、旧役員の端末からのアクセスを一括遮断できます。合言葉はスプレッドシートの「システム設定」シート、または本画面（管理者権限時）から変更可能です。

現在の利用権限: 👑 管理者権限
名簿の編集・削除・新規登録、役職やブロック設定、合言葉の変更を含む全機能が利用できます。
一般役員が名簿閲覧や帳票印刷、集金チェックを行うための合言葉です。
名簿の新規追加・編集・削除や設定変更ができる管理者専用合言葉です。
📋 Googleフォーム連携ガイド

入会申込用Googleフォームを作成し、回答先を上記スプレッドシートの「入会申込_フォーム連携」シートに設定することで、住民がスマホから送信した申込がアプリの「入会申請受付」タブに自動到着します。

推奨するGoogleフォームの設問例:
  • 氏名（必須） / フリガナ（必須）
  • 電話番号（必須） / メールアドレス
  • 住所（番地・建物名・部屋番号）（必須）
  • 世帯人数（同居のご家族の人数）
  • ご家族構成・続柄・年代
  • 希望の班または近隣の目印
  • その他ご要望・防災時の配慮希望など
📖 役員向け利用マニュアル（配布・印刷用）

役員の年度交代時の引き継ぎや、新任役員への配布・説明用マニュアル（A4用紙対応）を印刷・ダウンロードできます。

自治会員名簿の閲覧・管理

個人情報保護のため、役員に配布された合言葉（パスコード）を入力してください。

💡 権限について:
・「一般役員用合言葉」: 名簿の閲覧・集金チェック・印刷が可能です。
・「管理者用合言葉」: 名簿の登録・編集・削除や各種設定が可能です。
📖 使い方・初期設定ガイド
🖨️ 印刷用マニュアルを開く

STEP 1 Googleスプレッドシートとの初回連携（役員全員の手順）

自治会スプレッドシートの名簿データを手元の端末に読み込むため、初回に1回だけ連携URLの設定を行います。
上部メニューの「⚙️ 設定」タブを開き、少し下にスクロールして「Google Apps Script Web App URL」を入力し「保存して接続テスト」をクリックしてください。

  1. 管理者から共有された「Google Apps Script Web App URL」をコピーします。
  2. 名簿アプリの 「⚙️ 設定」 タブを開き、画面を少し下にスクロールします。
  3. 「Google Apps Script Web App URL」枠に貼り付け、「保存して接続テスト」 をクリックします。
  4. 右上が「接続成功 / 同期完了」になれば連携完了です！画面右上に【🔒 未認証】ボタンが表示されます。

STEP 2 「🔒 役員合言葉（パスコード）」の入力と画面起動

スプレッドシートの同期が完了すると、画面右上に【🔒 未認証】ボタンが表示されます。クリックして役員合言葉を入力してください。

・👤 一般役員合言葉（初期値: roster2026）: 名簿閲覧、集金チェック、帳票印刷のみ可能（編集不可の安全モード）。
・👑 管理者合言葉（初期値: admin2026）: 名簿の新規追加・編集・削除、役職・合言葉の設定変更が可能です。
※認証完了後、いつでも右上のバッジ（👑/👤）からログアウト（未認証に戻す）が可能です。
